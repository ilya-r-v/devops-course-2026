# Git в VS Code vs терминал

## Что удобно в VS Code
1. Diff «до/после» по клику на файл — изменения видно сразу.
2. Встроенный редактор конфликтов (Accept Current / Incoming / Both).
3. GitLens: git blame по строкам и история файла без лишних команд.

## Что удобнее в терминале
- Interactive rebase, cherry-pick и reflog: в IDE они скрыты или неудобны, а на сервере по SSH есть только терминал.
