# Git vs SVN

1. **Почему ветвление в Git «дешёвое», а в SVN «дорогое»?**
   В Git ветка — это лёгкий указатель на коммит (файл с хешем), создаётся мгновенно и ничего не копирует. В SVN ветка — это копия директории на центральном сервере (`svn copy`), она создаёт новую ревизию и зависит от сети. К тому же слияние в SVN исторически слабее отслеживает, что уже влито.

2. **Можно ли в SVN сделать коммит без интернета?**
   Нет. Коммит в SVN — это запись на центральный сервер, а локально есть только рабочая копия. Без связи можно править файлы, но не фиксировать историю. В Git коммит локальный, а сеть нужна только для push/pull.

3. **Когда SVN может быть предпочтительнее?**
   - Legacy-проекты и госсектор/банки, где всё построено вокруг SVN и миграция дорогая.
   - Огромные бинарные файлы (игровые ассеты, CAD), где нужна блокировка файлов (lock) и не нужна полная копия истории.
   - Строгий централизованный контроль доступа по путям внутри одного репозитория.
